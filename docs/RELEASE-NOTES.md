## Capture Access 0.8.0

- Windows 与 macOS 均加入 GitHub 正式版本检测、手动检查和下载入口。
- 自动检查更新默认开启，每天最多检查一次，可在设置中关闭。
- 两个平台均加入登录时启动选项，默认关闭。
- Windows 重新整理主界面和设置窗口，统一 Capture Access 的视觉与操作布局。
- macOS 保留普通/特殊区域截图、选区调整、双热键、历史记录、关于和 MIT 软件许可。
- README 增加平台对比、安装与使用步骤、更新说明及标注为示意的虚构数据图片。

### 下载

- `CaptureAccess-Windows.zip`：完整解压后运行 `CaptureAccess.exe`；支持 Windows 10/11 的 x86/x64 桌面应用。
- `CaptureAccess-macOS-universal.zip`：macOS 14+，同时包含 Apple Silicon 与 Intel 架构。
- `SHA256SUMS.txt`：两个压缩包的 SHA-256 校验值。

此处的 Mac 包由 GitHub 的干净构建环境生成，使用临时（ad-hoc）签名，未进行 Apple Developer ID 签名或公证。
更新通过浏览器下载，应用不会自动替换或执行下载文件。替换旧版本前请退出工具。

仓库只收录公开源码和虚构示意图；不会随发布包含用户截图、历史记录、本机诊断文件或个人签名证书。
