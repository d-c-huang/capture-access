# 文档示例素材

本目录中的 SVG 均为按产品功能绘制的**界面示意图**，不是实际桌面截图。README 中也明确标注了这一点。

| 文件 | 展示内容 |
| --- | --- |
| `macos-overview.svg` | macOS 的截图入口、预览、本地历史和导出 |
| `region-selection.svg` | 框选、移动或缩放、确认并复制的操作流程 |
| `windows-overview.svg` | Windows 的窗口列表、保护处理和恢复入口 |

素材只使用虚构的“示例应用”、测试窗口、示例数字及几何风景。没有读取或嵌入真实聊天、联系人、桌面、窗口标题、账号路径、访问令牌或截图历史。SVG 不包含脚本、远程图片或嵌入的真实照片。

更新文档时请继续使用虚构演示内容。不要将真实截图仅作模糊处理后直接提交；图片中的敏感内容、隐藏元数据或原图副本都可能被一起保留。
