macOS 手动验收
==============

准备
在 macOS 14+、Xcode 15+ / 对应 Command Line Tools 环境运行 bash macos/build.sh。
从生成的 macos/dist/CaptureAccess.app 启动，保留 macOS 版本、CPU 架构、目标应用名称和版本。
同时检查 Intel 与 Apple Silicon 时，请使用 --arch universal 构建并分别实测。

1. 首次使用与授权
点击“选择窗口并截图”，确认系统窗口选择器出现。
取消选择后界面恢复可用，没有新增预览、保存文件或剪贴板写入。
若系统要求权限，拒绝时应显示错误和授权入口，不能显示截图成功。
在系统设置授权后，必要时重新启动应用，重新选择窗口应能再次尝试截图。

2. 正常窗口
选择一个包含可识别文字与颜色的普通窗口，确认截图中仅包含所选窗口。
确认预览不是黑图、旧图或其他窗口；部分遮挡与多显示器也需要测试。
在 Retina 显示器上核对像素尺寸与内容比例。
截图操作只在按钮触发时执行，没有持续录制或音频采集。

3. 保存与复制
保存 PNG，用“预览”打开并核对内容、透明度和像素尺寸。
取消保存对话框时，不应新增文件。
复制图片，粘贴到“预览”或其他支持图片的应用，确认图像一致。
清除预览后，之前主动复制的图片仍可粘贴。

4. 再次截图与失效
改变目标窗口内容，再点击“再次截图”，应得到新内容和新时间。
关闭目标窗口后再次截图，界面应报错或超时退出忙碌状态，旧预览不能标成新图。
截图过程中取消操作，后到的结果不能覆盖当前状态。
取消并重新选择其他窗口后，预览必须来自新的选择。

5. 旧式截图保护
点击“打开测试窗口”，在系统选择器中选择独立的 Capture Access Demo 应用窗口。
分别在“旧式窗口保护”勾选和取消时测试。
记录目标系统对 sharingType = none 的实际行为；不要求所有 macOS 版本结果一致。
如有实际需要使用的第三方应用，再测试其窗口并记录结果。
DRM 或应用主动隐藏的内容不可捕获，不应把返回了 PNG 当作解除成功。

6. 超时与资源
目标挂起或捕获不返回时，约 15 秒后界面应结束忙碌状态，并允许重新选择。
超大窗口保持图像比例，并显示缩小提示；应用不应因尺寸值异常而崩溃。
关闭主窗口后进程退出，系统不应继续显示本应用处于捕获活动状态。

反馈
提供 macOS 版本、Intel/Apple Silicon、目标应用名称/版本、预览是否完整、保存与复制结果、界面错误和日志。
